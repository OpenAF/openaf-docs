# oPack catalog

This catalog covers **126 packages** in the [pinned upstream snapshot](../../source-snapshot.md). Package names and requirements come from their manifests. Install with `opack install <name>` and load the documented entry point; an installation does not automatically load every library.

Versions below identify source package metadata, not a guarantee that a package mirror has published that revision. Requirements are the declared package dependencies; linked guides describe extra services, native libraries and credentials. A source/manifest link means no root README is available.

For package management see [oPacks](../advanced/opacks.md). For database connections see [JDBC drivers](jdbc-drivers.md) and [JDBC URL policy](../advanced/jdbc-url-policy.md).
